# Research: Vượt Ải Dungeon (Spec 028)

## Canonical Analysis

1. **Party Entry & Token Consumption**:
   - Only party captain can register for Vượt Ải challenge.
   - Requires 2..8 party members, all level 50+.
   - Leader pays 10,000 silver.
   - Each member must possess at least 1 Sát Thủ Giản token (`VuotAiTokenGenre=6, Detail=1, Particular=400`), which is consumed upon entry.

2. **28 Canonical Waves & Timer**:
   - 28 waves of increasing difficulty.
   - Fast challenge runs on an 18-minute countdown (`1080 seconds`).
   - Wave Timer Board announces status every second using the canonical `<#>` banner format.

3. **Milestone Chests**:
   - Waves 7, 14, 21, and 28 produce milestone clear chests (Bảo Rương Vượt Ải).
   - Claiming chests grants substantial experience, silver, and rare equipment drops.
